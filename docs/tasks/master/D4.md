# D4. Typing and logging ratchets (Phase D; old ref P17)

**Why.** `noExplicitAny` is off with 126 `any` usages; 81 `console.log/info/debug` calls remain although a leveled logger exists (`packages/agent-core/src/utils/logger.ts`).

**Do.** Set `noExplicitAny` to `warn` in `biome.json`, generate `tooling/scripts/any-baseline.json` (count per file) and add a CI script failing when any file's count increases or a new file adds one; then remove every `any` from the security-critical files (`tools/approval.ts`, `runtime/trusted-sender.ts`, `apty/external-messaging.ts`, `apty/network-capture-session.ts`, `tools/devtools.ts`, `ws-bridge/*`, `apps/mcp-bridge/src/*`) and report counts before and after. Replace the remaining `console.log/info/debug` in non-test source with the logger, keeping the production strip of debug output, then add Biome `noConsole` allowing `warn` and `error` (documented exceptions only for tooling scripts). Behaviour must not change; no log line may print keys, tokens, URLs with query strings or page content.

**Tests.** The baseline script passes and fails on an added `any` (prove locally, do not commit); logger unit tests where logging is behaviour (approval and MCP paths); assert the production `dist` has no debug console output.
