# C1. Live model list, tool-calling probe, preset audit (Phase C; old ref P06)

**Why.** The model combobox and "Add custom model" exist (`packages/ui/src/components/settings/index.tsx`). `handleTestConnection` is in `apps/browser-extension/src/entrypoints/options/index.tsx` and uses `describeConnectionTestError`, `createAIProvider` and `validateHostUrl` in `apps/browser-extension/src/services/ai-provider.ts`. The 15 presets are in `packages/agent-core/src/config/ai-providers.ts`; some model lists are stale and Replicate is not an OpenAI-compatible API. Three native adapters (OpenAI, Anthropic, Google) plus an OpenAI-compatible one exist. Neither a live model fetch nor a tool-calling check exists, and the agent needs function calling.

**Do.**
1. A **Fetch models** button beside the model field. OpenAI-compatible: `GET {baseUrl}/models` with a Bearer key. Anthropic: its models endpoint with `x-api-key` and the `anthropic-version` header. Google: its models list endpoint. Follow each provider's official documentation (if a detail differs from this prompt, follow the docs and note it in `REVIEW.md`). Respect `validateHostUrl`, HTTPS except confirmed loopback, never log keys, cache in memory 10 minutes per provider and host, name errors (401, 403, 404, 429, network); on failure keep presets and manual entry.
2. A **tool-calling probe** in Test connection: after the basic check, send one minimal request with a single trivial tool and a prompt that requires calling it; classify "supports tools: yes / no / unknown" (timeout 15 s, one retry), show a badge, warn before selecting a model that failed. Use existing adapters, no new dependency.
3. **Preset audit:** for each of the 15 presets confirm the base URL and that it works with the OpenAI-compatible adapter; remove or flag `experimental` any that cannot (for example Replicate); verify the Cohere compatibility URL and the Azure deployment URL form from official docs. Treat built-in model names as "suggested" only, prefer provider "latest" aliases where they exist, otherwise leave suggestions empty. Do not hardcode names you cannot verify. Preserve all current multi-provider and custom-model support.

**Tests.** Unit: parsers per provider with fixtures; probe classification. e2e: extend `startMockModel` to serve `/models` and to answer or refuse the tool probe; cover fetch success, 401 with fallback, and each probe result in the real Settings page.
