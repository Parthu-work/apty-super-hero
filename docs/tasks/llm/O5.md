# O5: show what was sent

Status: done (see REVIEW.md at the Phase A checkpoint). Tests:
`runtime/request-reports.test.ts`, `aipex.test.ts` (filters get instructions
and tools), `settings/recent-requests.test.tsx`, `preflight-panel.test.tsx`,
`hooks/use-request-reports.test.ts`, `llm-outbound.e2e.test.mjs` (O5).

As built: the report filter runs last in the outbound chain. Reports live in
`chrome.storage.session` (memory only, cleared when the browser closes) so
the Options page can read what the side panel sent; no permission is added.
Each report holds a time, the redaction mode, token estimates (system prompt,
tool schemas, history, tool results, total) and counts (items, tool results,
stubbed, cut, screenshots). No text, URLs or tool names. To size the system
prompt and tool schemas, `OutboundFilter` now receives the call's
instructions and tools as a second argument.

Partial: the spec's "values masked" count is not reported; the sanitizer
does not count its replacements, and counting them means a second pass over
every result.

Keep the last 5 request reports in memory: counts and token estimates only
(system prompt, tool schemas, history, tool results, items stubbed or capped,
values masked). No content, no URLs.
