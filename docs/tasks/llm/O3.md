# O3: mask and cap the page-reading tools

Status: done (see REVIEW.md at the Phase A checkpoint). Tests: `value-policy.test.ts`
(dom-snapshot), `__tests__/name-is-value.test.ts`, `runtime/value-policy.test.ts`,
`snapshot-provider.value-policy.test.ts`, `tools/value-results.test.ts`,
`tools/page-reading-policy.test.ts`, `redaction-mode-control.test.tsx`,
`llm-outbound.e2e.test.mjs` (O3).

As built: the policy is applied where the snapshot is formatted for the model
(`formatSnapshot` in `automation/snapshot-provider.ts`), so it covers both the
CDP (focus mode) and DOM (background mode) snapshots and every caller. It
masks or drops: editable nodes' values, their text children, a name taken
from the value (collector flag `nameIsValue`), and the chosen `option` of a
select (CDP lists options as children). `get_editor_value` returns `[masked]`
or a "withheld" refusal; `get_page_metadata` drops (Strict) or masks
(Standard) URL query values. `take_snapshot` is capped at 4,000 tokens with a
note pointing to `search_elements`. Not covered: checkbox and radio states,
and page text (documented in PRIVACY.md).

`collector.ts` masks only `type=password`. Add a pure
`valuePolicy: "show" | "mask" | "withhold"` (default `"show"`) to the
`dom-snapshot` formatting/collection.
