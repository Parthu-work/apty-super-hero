# O4: screenshot consent

Status: not started.

`capture_screenshot` and `capture_tab_screenshot` send pixels with no
approval. Add `screenshotPolicy: "ask" | "allow" | "never"` (default
`"ask"`) to `AppSettings`.

- Gate both tools with `gateRiskyAction` (`tools/approval.ts`); the prompt
  is `apps/browser-extension/src/components/approval-prompt.tsx`.
- `capture_screenshot_to_clipboard` is unaffected (nothing leaves the device).
- MCP calls follow the same path. Translate new strings in `en.json` and
  `zh.json`. Settings control in the Data-handling card.
- Tests: policy matrix unit tests; red-green; e2e: ask -> deny returns
  `denied`, allow -> captures, never -> refused.
